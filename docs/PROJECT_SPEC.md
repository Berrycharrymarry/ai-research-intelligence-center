## 完成目标

1. 整卡旋转缩放；悬停轮廓高亮；点击与拖动可靠区分。
2. 点击可拆总成，经过可见的三维拆离轨迹到观察位，镜头平滑聚焦；父总成仍可辨。
3. 连续进入子组件、细分零件；每个有实际内部结构的主要总成有 L1→L2→L3 路径。原子件终止并说明原因。
4. 独立旋转当前观察件不带动背景装配，返回与复原精确重建原始位置。
5. 零件树可访问遮挡件；提供遮挡物隐藏/半透明和整体爆炸视图。
6. 面包屑、名称/功能/连接/父节点/层级/可信度信息、上一层、当前复原、整卡重置、自动旋转与 X-Ray 完整。
7. 动画中快速点击、返回、重置、尺寸变化、离开路由均不产生漂移、重复对象或泄漏。

## 结构真实性规则

- `service`：宏观紧固/插接分离，路径是教学拆装路径，不承诺实物无工具维修步骤。
- `bonded`：焊接、钎焊、胶接、层压、封装内部。只有进入明确标记的“内部示意”模式后展示分离，持续显示“结构示意，非无损拆卸”。
- `integral`：扇叶与轮毂一体件、螺丝头杆、开孔/印字/PCB 金手指等不可机械拆分；可选中、高亮、观察，但不凭 Mesh 数量拆开。
- `evidence` = photo / existing_model / conceptual。existing_model 只说明继承了模型，不能当作实物工程证据。新增不可证实内部件一律 conceptual，并标注演示数量/尺寸。
- 图形装饰、开孔是 feature，不能创造没有几何的可移动“零件”。分组 region 只是导航，不能计入物理拆解深度。
- 禁止虚构散热均热板；沿用模型已有三根热管和接触板，不混入另一个型号的互斥结构。

## 范围与预算

完整支持三风扇、外壳、散热器、PCB/GPU/显存/VRM/供电/PCIe、背板、I/O。GPU 和显存封装内部、PCB 示意板层、风扇电机等仅补必要可讲解几何，不制作晶体管、电路仿真、导线走线或实物维修指导。
初始预算：GLB ≤12 MB；渲染实例三角形 ≤350k；普通质量总 draw calls ≤1200（含高亮/阴影），唯一几何 ≤100k 三角形。阴影只由壳、风扇和少量宏观件投射，不能让160鳍片与164接点都重复进shadow pass。高亮最多一个 hover + 一个 selected 装配；不能逐个克隆全部共享材质。性能以 TEST_PLAN.md 实测门槛为准。
