# 交互行为规范

## 默认整卡与选择

首次进入：装配完整、三风扇朝用户、I/O在左、PCB边在下；暗色环境中白粉外观仍可辨；不自动爆炸。加载时显示进度阶段和重试，不以图片伪装已加载模型。
指针hover只高亮当前上下文直接子装配的全部renderables，显示名称；根层命中任何fan叶片都解析到fan.NN。点击阈值：pointerdown/up移动≤5 CSS px、同一pointer且无Orbit drag；射线NDC由canvas DOMRect计算，与DPR无关。拖动结束不可再触发click。

点击可拆节点：高亮→必要遮挡总成先平滑让位→沿安全方向拔离→移动到观察位→相机平滑framing→信息与path提交。原父上下文保留，必要时弱化到低亮/半透明。不能只隐藏其他对象声称拆离。
原子part仍可被选中观察并在允许joint模式下从父组件分离，但没有“继续拆解”。feature/region只高亮/介绍/定位其owner，不启动detach。

## 深入、独立旋转与返回

已进入装配时，下一次拾取只解析其直接子节点；点击已选装配可再次ENTER，或用明确“展开内部”按钮。所有primary分支都有tree路径，即使细小零件难以点击也不丢失访问。
进入观察后默认“转动部件”：左拖仅改变当前节点inspectionQuaternion，背景及祖先固定；滚轮缩放由相机控制。可切换“环绕场景”。整卡层左拖默认Orbit。双指只缩放，第二指加入立即取消单指部件drag；禁止两套controls同时处理同一拖动。
进入子级时冻结父级当前观察姿态，保存父相机/观察状态，子级目标世界点转换到父当前局部；返回时子件回父绑定位置和基准姿态，恢复父镜头与父观察旋转。BACK不等于整卡复原。
RESTORE_CURRENT：当前context的所有后代回到在该context内的绑定位置，保留本context的拆离位置；若当前为leaf仅清除其观察旋转，显示原因。RESET_ALL：所有层级offset/rotation归零、path=[gpu]、恢复原显隐/材质/相机、关闭爆炸/X-Ray/自动旋转。

## 直接树跳转与遮挡

树点击深层节点不直接瞬移：计算当前path与目标路径LCA，先平滑回到共同祖先，再逐级进入目标路径。可以缩短中间steps时长，但至少可见外部总成让位和目标拆离。所有动作由同一个controller串行提交，不用递归同时dispatch。
板上GPU/显存/VRM定位需先把shroud、三fan和cooling让位；按layoutPlanner的service corridor退到外部后再停车，不让芯片穿过仍闭合的散热片。记录自动让位者的原状态，BACK/RESET恢复。显式用户隐藏与临时occlusionOverride分开，不覆写用户选择；RESET恢复全部默认。
提供“隐藏遮挡”“半透明遮挡”两种策略。内部示意仍必须执行零件真实3D分离，透明只帮助看到路径。透明遮挡不抢占命中：当前context可拾取集合过滤；被隐藏件可从树选中并临时显示，树眼睛状态注明临时显示。

## 机械拆解与内部示意

叶轮叶片/轮毂/外圈一体件、螺丝头杆、印字、开孔为原子/feature，不能凑层数。
GPU/显存封装、PCB层压、VRM内部、风扇电机及钎焊鳍片：入口显示“查看内部示意”。开启conceptual后允许bonded子件分离，界面持续显示“内部结构示意，非无损拆卸”；未知结构的形状/数量不可写成该型号真实规格。关闭conceptual自动复原示意级并退到合法祖先，不留下漂浮的die。
树可以显示这些子节点但在未开启时带提示；用户明确点击“查看内部示意”即可进入，无须聊天确认。

## 爆炸视图

只有根层layout=exploded；从深层开启时先递归复原→根层→分阶段展开8个L1宏观总成。只展开总成，不一次抛开160鳍片或全部焊球。关闭返回精确原位；点击爆炸中的部件先保持当前世界姿态建立路径，再由controller回收其他宏观偏移到上下文停车状态，不能重复叠加exploded+inspection的offset。实现简化允许先平滑合拢，再按选择拆离，需保留selected intent。
整体爆炸仍显示tree、信息、半透明、复位。相机切到能观察Z间隔的3/4角而非正面投影重叠。

## 中断与异常规则

连续SELECT同一目标为幂等；不同SELECT只保留最新intent。RESET优先级最高，立刻取消旧计划，从当前可见pose平滑回home。BACK在ENTER未完成时回最近committed context，不弹出尚未提交的frame。Hover在过渡中冻结或清空，UI显示busy但BACK/RESET可用。
Esc取消当前过渡并回最近已提交状态；丢失pointercapture/窗口blur释放drag；prefers-reduced-motion用≤150ms线性/淡变，无强制旋转，仍写精确终点。
单个资源或manifest故障需显示可诊断错误；不悄悄丢弃缺失部件后宣布成功。
